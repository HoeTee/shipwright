# Skills

[中文](skills.zh-CN.md) · [日本語](skills.ja.md) · [한국어](skills.ko.md)

The [README](../README.md) shows the eight core skills.
This page lists all 48 skills.
Each line is one job.

shipwright-autopilot, shipwright-swarm, shipwright-arena, and shipwright-eval stay off until you ask.

## Start

| Skill | What it does |
| --- | --- |
| [shipwright-flow](../skills/shipwright-flow/SKILL.md) | Selects the stage, the scope, and what you allow. |
| [shipwright-help](../skills/shipwright-help/SKILL.md) | Shows the card and a prompt. It does not start work. |
| [shipwright-setup](../skills/shipwright-setup/SKILL.md) | Sets the model for each role and the Git host. |
| [shipwright-rules](../skills/shipwright-rules/SKILL.md) | Drafts project rule files. It writes them after you agree. |
