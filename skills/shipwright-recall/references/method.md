# Restore the current task

用于恢复会话、交接或解释当前进度。先有当前事实，再使用历史材料补上下文。

## Input and output

输入为目标仓库、任务或 PR 标识以及要恢复的范围。输出为目标、当前版本与阶段、已确认授权、仍有效的证据、未完成项和下一步。

## Steps

1. 核对当前仓库、分支、HEAD、工作树和已存在的任务记录。
2. 按任务标识查相关历史与产物；仅调查本项目，不将其他项目的习惯当成事实。
3. 逐项比对历史结论对应的版本、环境和输入。旧报告仅作为线索。
4. 保留用户已确定的范围、审批和审查轮次。恢复会话不能重置计数或扩大授权。
5. 给出当前状态摘要，证据失效或缺失时单列。未完成的原目标继续保留。

## Checks and boundaries

正例：说明旧报告针对旧提交，当前变更需要补验证哪些部分。
反例：根据最近一条成功消息就声称当前 PR 已通过或目标环境已更新。

只问进度时回答进度；恢复执行时将该摘要交回原阶段。
