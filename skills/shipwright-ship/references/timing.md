## Continue from the current stage

复用任务的仓库、平台入口、工具能力、授权范围、已读指令与下一动作。只有版本、指令或能力变化时补读相关部分；跨上下文恢复先读简短状态与必要证据，不重新运行初始化流程。

连接器已满足操作时，不探测或安装另一个 CLI。调用前按当前工具描述核对参数；缺少某一能力时只补该能力。文件检索限定目录/类型，长日志先提取摘要、失败位置和计数，不向上下文倾倒完整日志、依赖目录或秘密。

正例：已有连接器能读取 PR 和 CI，就复用它；缺少 push 事件查询时只补相应只读入口。
反例：每次恢复都重读全部参考、枚举全部工具或重新检查所有平台 CLI。

## Parallel time

本地必需检查按项目安排执行。CI 与独立 AI 审查通常并行；任一失败由 Agent 处理，两者对当前版本通过后才进入最终人审。不为等待 CI 完成而让无依赖的材料准备停下。

在阶段开始/结束或关键工具返回时记录时间、责任人、版本和结果链接。区分执行、排队、等待业务决定、解释问答和现场结果；这些类别可能重叠，不能把各运行时长相加成墙钟耗时。缺少细分计时就标明区间与不确定性，不推算未经测量的节省百分比。

某步骤明显超出本项目已观察到的正常范围时，说明卡在代码、依赖、排队还是编排，继续可独立工作；不要无依据地保证固定分钟内完成，也不要把普通技术排障交给用户。

正例：报告 CI 的创建至结束区间，同时说明多个 PR 的 CI 有重叠；单列用户决策与说明材料耗时。
反例：声称总共三小时都在跑测试，或把流程说明不清导致的反复追问全部归为用户等待。
