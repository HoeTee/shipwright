# Calibrate the wording

在起草用户回答、Agent 指令或审核材料时使用。目标是让动作、对象、条件和证据容易理解，不改变原有判断。

## Input and output

输入为待表达的信息及其事实状态。输出保留同一含义、范围和不确定性的文本。检查可以与写作同时完成，不要求重复加载本文件。

## Checks

- 句子说明谁对什么做了什么。把抽象进展改成可核对的动作或结果。
- 结论先行，随后给必要依据。相同对象使用一致术语。
- 区分已完成、已验证、待确认、失败和未执行。
- 保留否定、条件、例外、版本、权限与风险边界。简化不能削弱含义。
- 删除重复铺垫和没有证据的强调，避免用篇幅或肯定语气制造可信度。
- 按目标语言调整表达，不硬套另一种语言的句法、标点或禁词表。
- 用户疲惫或要求明确决定时，给具体处理与实际状态，避免继续扩大备选清单。

正例：写“新增入口已经写入，尚未运行真实审查任务”。
反例：只说“能力已全面接通”，却没有执行证据。

表达校准不授权改代码、修改结论或删掉未解决问题。
